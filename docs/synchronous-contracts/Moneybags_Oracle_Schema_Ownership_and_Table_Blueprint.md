# Moneybags Oracle Schema Ownership and Table Blueprint

This is a documentation-only physical blueprint. Each service receives a separate Oracle user/schema. Relationships listed below are local to that schema; cross-service identifiers are opaque values and never cross-schema foreign keys.

## Global Oracle rules

- Flyway is the only production DDL mechanism; Hibernate uses `ddl-auto=validate`.
- Monetary values use `NUMBER(19,4)` plus an ISO-4217 `CHAR(3)` currency.
- IDs use `VARCHAR2(36)` UUIDs unless a stable business code is explicitly named.
- Business timestamps use `TIMESTAMP(6) WITH TIME ZONE` and UTC.
- Mutable aggregate roots carry `VERSION_NO` for optimistic concurrency.
- PII is encrypted or hashed according to lookup needs; logs and APIs mask sensitive values.
- Every mutable service has local idempotency and immutable audit tables.
